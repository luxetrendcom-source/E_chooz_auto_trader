E_CHOOZ AUTO TRADER — Powered by TradeMate AI

STARTER PROJECT
1. Extract this ZIP.
2. Open the folder and check that index.html, style.css, app.js, manifest.json, sw.js and netlify.toml are at the top level.
3. Deploy the folder to Netlify (or upload the files to a new GitHub repository and connect it to Netlify).
4. Open the deployed site on your phone.

CURRENTLY INCLUDED
- Mobile-first dark dashboard
- Sample forex watchlist
- Virtual demo balance
- Simulated paper-trade history
- Basic installable PWA files

IMPORTANT LIMITATIONS
- Market prices are illustrative sample values, not live quotes.
- This starter does not connect to a broker, MetaTrader, Supabase, or a real trading account.
- No real orders or real-money trading are supported.
- Do not add broker passwords or API secrets to frontend files.
